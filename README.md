# Dev Stack

A responsive React/Vite web app for exploring technologies and building a personal development stack.

## Tech
- React
- Vite
- Plain CSS
- React Toastify
- Local JSON data

## Features
- Responsive technology cards
- Add/remove technologies with duplicate protection
- Personal stack sidebar with Remove All
- Loading state and toast notifications
